Features

LocalNewsBreaker v1.0.8 — Web, Android & iOS

📥 Citizen reporting

  • Submit breaking news with headline, body, location, and category
  • Optional media attachments (photos via API upload)
  • Stories enter pending review until editors publish them
  • My Submissions when signed in — track pending vs published status

🤖 AI Truth Index

  • Each story receives a Truth Index score (0–100%)
  • Rationale explains factors: detail length, media, heuristics
  • Color-coded badges on feed cards (high / medium / low trust)
  • Insights tab shows distribution charts and averages

🌍 World feed

  • Published stories from GoDaddy API (/api/v1/news/)
  • Category tabs: World, Politics, Business, Tech, Science, Health, Sports, Entertainment, Local
  • Pull-to-refresh and hybrid fallback (live → cache → sample)
  • Story detail with full body fetch, share, and text-to-speech

🔎 Search & archive

  • Keyword search across published stories
  • Filter by category and status via API

📰 Daily newspaper (Papers tab)

  • Generate daily PDF from verified stories (/api/v1/generate-pdf/)
  • Edition metadata: today’s headline, story IDs, release workflow
  • Download static PDF at /media/newspaper.pdf
  • Archive past editions

✅ To-Do — Release checklist

  • Pre-seeded editor tasks: review, approve, generate PDF, release edition
  • Hybrid storage: Hive local first, cloud backup when signed in
  • client_uuid on create; server id saved for sync
  • Cloud sync button merges local and remote tasks

👤 Account & security

  • Register / sign in with JWT (username + password)
  • Profile via /api/v1/users/me/
  • Sign out and delete account (App Store / Play requirement)
  • Tokens stored locally in encrypted app storage (Hive)

☁️ Backend API

  • Production API: https://citizen-api.mywaitime.com/api/v1/
  • Health, news, submit, search, stories, PDF, editions, tasks, auth endpoints
  • PostgreSQL database on GoDaddy VPS
